# V3.0 页面与交互说明

> 对应需求基线：V3.0-R3
> 文档状态：交互基线已确认，待设计稿回填
> 更新日期：2026-08-24
> 适用范围：团队任务与版本排期

## 1. 全局边界

- 本期只支持桌面 Web，最小内容宽度按 1280px 设计；
- 任务面板和甘特图内容超出可视宽度时允许横向滚动；
- 手机端专用布局、手势交互和响应式重排不属于 V3.0；
- 所有项目成员拥有相同的任务与版本管理能力；
- 归档项目可查看但不可修改，所有写操作、拖拽和状态切换禁用；
- 项目知识库不属于 V3.0，不在导航中展示该入口。

## 2. 左侧导航

项目展开后的 V3.0 导航顺序为：

```text
项目名称
├── 需求
├── 访谈记录
├── 团队任务
└── 版本排期
```

- 点击项目文件夹只展开或收起，不切换主内容；
- 点击“团队任务”默认进入任务面板；
- 点击“版本排期”进入当前项目的版本模块；存在版本时默认显示最新创建版本，不存在版本时显示空状态。

## 3. 团队任务模块

### 3.1 任务面板

- 页面顶部提供“任务面板/甘特图”切换、任务名称搜索、状态筛选和全局“新建任务”；
- 默认筛选为“未完成”，即待开始和进行中；
- 搜索仅匹配任务名称，并与状态筛选同时生效；
- 全部项目成员始终显示，没有匹配任务时显示 0 个任务；
- 成员标题任务数使用当前搜索和筛选后的结果数；
- 成员标题不显示“…”菜单；
- 点击任务卡片打开编辑任务弹窗；拖拽手柄只用于同一负责人泳道内上下排序。

### 3.2 任务顺序

- 每个项目中的每位负责人维护一套稳定顺序；
- 全局新建或成员泳道新建的任务保存后放到该负责人泳道底部；
- 编辑任务并更换负责人后，任务放到新负责人泳道底部；
- 筛选后的任务保持原相对顺序，拖拽后保存到完整任务序列；
- 四个视图复用相同相对顺序，但只有团队任务面板可以拖拽；
- 排序保存失败时恢复到拖拽前位置并提示失败，不保留只存在于页面内的临时顺序。

### 3.3 新建任务

- 全局“新建任务”不预填负责人；
- 成员泳道“添加任务”预填当前成员；
- 版本成员分组“添加任务”预填当前成员和当前版本；
- 默认任务状态为待开始，默认优先级为 P1；
- 创建按钮在请求期间禁用，防止重复提交；
- 不预先判断或展示成员任务上限，泳道入口和负责人选项保持普通状态；提交创建后若服务端返回成员任务上限冲突，保留表单并提示“创建失败：该成员已达到任务上限”；
- 创建成功后关闭弹窗、刷新相关视图并显示成功提示；失败时保留已填写内容并显示失败原因。

### 3.4 编辑与删除任务

- 点击任务卡片、甘特图任务名称或任务条打开同一个编辑弹窗；
- 编辑负责人或所属版本只移动同一任务，不生成副本；
- 修改负责人后若服务端返回成员任务上限冲突，保留表单并提示“保存失败：该成员已达到任务上限”；
- 改给尚未参与版本的成员时，保存成功后自动把该成员加入版本参与人员；
- 点击“删除任务”打开二次确认；弹窗不展示任务名称，只显示通用的不可恢复警告；确认按钮在请求期间禁用；
- 删除成功后关闭两层弹窗，并从团队任务、版本排期和两个甘特图同步移除；
- 删除失败时保留任务并展示失败提示。

### 3.5 表单校验

- 任务名称、负责人、任务状态和优先级必填；
- 任务描述最多 500 字，达到上限后不允许继续输入，存量超限内容保存时提示修正；
- 开始日期和预计完成日期可独立填写；
- 两个日期都填写时，预计完成日期不得早于开始日期；
- 日期校验失败时在对应字段下方显示错误，不关闭弹窗；
- P0～P3 分别为重要紧急、重要不紧急、紧急不重要、不紧急不重要。
- 成员任务上限按该成员在当前项目中的全部任务计算，不受状态、版本、搜索或筛选条件影响。

### 3.6 团队任务甘特图

- 左侧显示项目全部成员及符合搜索、筛选的任务；
- 只有开始日期和预计完成日期都存在时绘制任务条；
- 所有任务条统一蓝色，不通过颜色编码状态或优先级；
- 甘特图不显示任务拖拽图标，不允许移动、缩放或拖拽修改日期；
- 默认周刻度，支持日、周、月和横向滚动；
- “今天”把当天定位到可视区域中央；左右箭头按当前刻度移动一个可视窗口。

## 4. 版本排期模块

### 4.1 无版本状态

- 项目不存在版本，或最后一个版本被删除后，显示版本空状态；
- 空状态提供“创建第一个版本”按钮；
- 不自动创建默认版本，也不跳转到团队任务；
- 空状态下不展示无意义的搜索、筛选、编辑和删除操作。

### 4.2 版本切换

- 下拉只包含实际版本，不提供“全部版本”；
- 全部版本不区分状态，按创建时间倒序；
- 首次进入或重新进入模块时默认显示最新创建版本；
- 创建版本成功后自动切换到新版本；
- 列表与甘特图切换时保留当前版本、搜索、筛选和甘特刻度；刷新或重新进入模块后恢复默认状态。

### 4.3 创建与编辑版本

- 版本名称、开始日期、结束日期和参与人员必填；
- 版本默认状态为未开始；
- 结束日期不得早于开始日期，不同版本周期允许重叠；
- 版本至少保留一名参与人员；
- 成员名称下方只读展示现有部门名称，没有部门名称时不显示；
- 参与人员仍负责当前版本任务时，“移除”不可完成，应提示需要先转交任务或将任务移出版本；
- “清空”遵循同样校验，不能使版本变为零参与人员；
- 保存请求期间禁用提交按钮，失败时保留表单内容。

### 4.4 版本状态

- 点击版本状态徽标打开状态选项；
- 未开始和进行中之间直接切换；
- 切换为已完成时弹出确认，展示当前版本未完成任务数量；
- 确认完成只修改版本状态，不修改任何任务状态；
- 已完成版本重新切换为未开始或进行中时直接切换并显示成功提示；
- 状态请求期间禁用重复操作，失败时恢复原状态并提示。

### 4.5 版本排期列表

- 默认状态筛选为全部；搜索和筛选规则与团队任务一致；
- 始终显示当前版本全部参与人员，无匹配任务时显示 0 个任务；
- 参与人员任务数使用当前搜索和筛选后的结果数；
- 每个参与人员分组都提供“添加任务”，零任务时使用空状态入口；
- 点击任务名称或“编辑”打开任务编辑弹窗。

### 4.6 版本排期甘特图

- 只展示当前版本的参与人员和任务；
- 任务顺序沿用团队任务中的负责人任务顺序；
- 绘制条件、统一蓝色、只读行为和时间导航与团队任务甘特图一致；
- 版本周期只作为参考，任务条允许超出版本起止日期。

### 4.7 删除版本

- 点击“删除版本”打开二次确认；
- 确认内容展示受影响任务数量，并明确任务不会删除、只会解除版本关联；
- 删除成功后，原版本任务继续出现在团队任务中；
- 如果仍有其他版本，切换到创建时间最新的剩余版本；如果没有版本，进入版本空状态；
- 删除请求期间禁用确认按钮，失败时保留当前版本并提示。

## 5. 搜索、筛选与页面状态

- 团队任务默认未完成，版本排期默认全部；
- 搜索或筛选无结果时保留成员分组，并在分组内显示空结果；
- 当前访问期间切换列表与甘特图保留条件，刷新或重新进入模块恢复默认；
- 初次加载使用页面级加载状态，不先展示错误的 0 条结果；
- 加载失败显示错误状态和“重新加载”；
- 局部写操作失败使用就近提示，并恢复操作前数据；
- 归档项目的禁用操作需给出“项目已归档，仅支持查看”的可理解提示。

## 6. 设计交付深度

以下状态必须制作正式设计稿：

- 版本空状态；
- 完成版本确认；
- 删除版本确认。

以下状态可以通过现有组件规范与本说明实现，无需为每个页面单独制作完整高保真稿：

- 表单必填与日期错误；
- 描述长度限制；
- 加载、失败、无搜索结果；
- 请求中的按钮禁用；
- 参与人员不可移除；
- 归档项目只读。
- 创建或转交任务时服务端返回成员任务上限冲突。
