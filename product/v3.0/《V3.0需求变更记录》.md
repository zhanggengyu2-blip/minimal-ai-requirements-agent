## 2. 变更状态

- 待评估：已提出，尚未完成影响分析；
- 待确认：影响分析已完成，等待产品决定；
- 已批准：进入当前版本并更新基线；
- 已延期：记录到后续版本，不进入当前基线；
- 已拒绝：不执行；
- 已完成：文档、设计、开发和测试均已同步。

## 4. 使用规则

- 一项变更只登记一次，后续讨论追加到同一编号；
- 多个页面受同一业务规则影响时合并登记，不拆成重复变更；
- 只有“已批准”的变更可以修改冻结 PRD；
- 变更完成后，应同时检查页面结构、交互说明、设计、接口和测试是否需要更新。
