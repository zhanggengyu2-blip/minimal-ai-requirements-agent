# 极简AI需求管理智能体 — 本地 Figma 插件

该插件不依赖 Figma MCP。运行后会在当前 Figma Design 文件中生成原生、可编辑的桌面端原型图层。

## 生成内容

- 1440×900 桌面端项目需求泳道页面
- Codex 风格左侧项目文件夹导航
- 多项目及其「需求」子标签
- 待采纳、已采纳、已实现、不采纳四个状态泳道
- 按 P0 → P3 排序的需求卡片
- 需求ID、内容摘要、提交人头像/昵称、优先级
- P0、P1、P2、P3 四个原生需求卡片组件变体
- 所有页面、文字、颜色、卡片和布局均为 Figma 原生可编辑图层

## 导入方式

1. 使用 Figma 桌面端打开任意 Figma Design 文件。
2. 打开菜单：`Plugins → Development → Import plugin from manifest…`。
3. 选择本目录中的 `manifest.json`。
4. 再次打开：`Plugins → Development → 极简AI需求管理智能体原型生成器`。
5. 插件运行完成后，会新增：
   - `项目需求泳道`
   - `组件`

## 重复运行

插件不会删除已有页面。重复运行时，新页面会自动增加数字后缀，例如：

- `项目需求泳道 2`
- `组件 2`

## 字体

插件优先使用 `Noto Sans SC`。若当前 Figma 环境没有该字体，会自动回退到 `Inter`。

## 文件说明

- `manifest.json`：Figma 开发插件清单
- `code.js`：一键生成原型的插件代码
- `README.md`：导入与运行说明
