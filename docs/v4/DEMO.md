# 面试演示脚本

## 演示前准备

按根 README 启动后端/API + Worker（后台事件进程）和原 Vue 前端。登录管理员；为项目添加演示员工。三个模型均为服务端真实配置：Coo 对话模型、Embedding、可选 Rerank。没有 Key 时界面会明确失败；自动测试使用受控模型响应，不能称为真实付费模型验证。

创建「电商履约协作」项目，业务上下文：我们经营电商业务，仓储负责发货，客服负责同步客户进展；超时订单需要先调查原因，再明确责任人与截止时间。将演示员工加入项目。

在知识库创建项目分类「履约处理规范」，正文：

> 已付款超过48小时未发货，先联系仓储核实库存与拣货状态；缺货由采购确认补货计划；每次进展写入跟进任务留言。未经确认，不得向客户承诺具体发货时间。

预览切片、保存草稿、发布。确认 v1 为 PUBLISHED，召回测试「订单超时未发货如何处理」显示片段来源、向量/关键词召回和 Rerank 或降级标识。

## 场景一：需求分析与协作（约5分钟）

1. 在项目需求管理创建：「客服希望自动发现超过48小时未发货的订单，通知仓储调查，并跟踪处理进度。」勾选 AI 分析。
2. 展示需求先保存，随后显示 Coo 的十字段分析：标准内容、业务目标、类型、优先级、真伪、重复关系、判断依据及总结。失败时展示原文保留和错误原因，可在详情点击「Coo 分析需求」重试。
3. 点击全局「Coo AI 同事」，会话携带当前项目。输入：「调查这条需求，查询历史相关需求、履约处理知识和当前任务，给我协作建议。」
4. 展开工具过程，说明由模型根据目标选择工具，业务服务仍执行权限规则。展示本次授权检索的来源片段。
5. 输入：「为这件事建议一个跟进任务，先查询项目成员，把任务交给合适的成员。」查看具体任务名、负责人ID、说明；确认前任务不会创建。点击「确认执行」，跳转关联真实任务。
6. 可继续让 Coo「将刚创建的任务改为进行中」：它先读取任务 revision，再提出状态变更，员工确认后执行；员工先修改任务会使旧建议因 revision 冲突而失败，不覆盖新内容。
7. 员工留言并回复；让 Coo 调查留言。不勾选授权时 Coo 留言需要确认；本轮勾选授权后可直接发表，任务中显示「Coo · AI 同事」与运行记录。

## 场景二：履约异常主动跟进（约5分钟）

1. 进入「Coo → 主动工作与事件」，选择项目，输入模拟订单号 DEMO-ORDER-001，保存异常。
2. 明确告诉面试官：这是模拟 ERP 订单，尚未接入真实 ERPNext，没有真实库存和物流操作。
3. 展示事件 PENDING → PROCESSING → SUCCEEDED（调查完成）。可以关闭页面后重新打开，处理仍由后台 Worker 执行。
4. 「查看调查」展示 Coo 自主决定的工具调用：模拟订单适配器、项目成员、知识或任务等。工具序列取决于模型，不保证每次完全一致；没有必要处理时，允许只给出判断。
5. 若模型未主动给出任务建议，可在 Coo 会话中引用订单号，明确目标：「调查这个模拟订单，并提出联系仓储的跟进任务」。检查完整建议后确认，创建真实内部任务。
6. 员工更新任务状态为进行中、留言「已联系仓库，正在核实库存」。新增事件可触发下一轮调查与跟进建议。Coo 自身留言不会再次产生留言事件。
7. 展示失败事件原因与重试、事件去重和执行记录。重复同项目同模拟订单号返回同一事件。

## 可以准确介绍的技术

模块化单体；复用 FastAPI/SQLAlchemy 与原 Service；有 Schema 的工具注册表；有轮次、上下文、时间和 Token 预算的单 Agent；确定性需求分析 Workflow 与自主 Runtime 复用；项目与部门 ACL；私人会话；数据库 Outbox（与业务同事务保存事件）及租约；写入人工确认；SQLite 保存向量、中文词法/余弦双路召回、RRF 和可配置 Rerank；版本有效期与引用白名单。

知识技术来自客服项目 foundation，底层工程有 AgentServe Apache 2.0 来源。应说明复用和本次权限/集成改造，不能全部描述为原创。

## 需要坦诚说明的边界

- 原型规模，SQLite/Python 检索面向小规模演示，没有生产吞吐或业务收益证明。
- ERPNext、真实订单授权与同步尚未接入。没有独立 Goal/Plan/长期个人 Memory 系统；保存的是有限会话上下文及可追踪执行。
- 尚无流式响应，前端等一轮运行完成后显示工具结果，后台记录在工具执行后持久化。
- 企业知识由管理员选择全员/部门；项目知识复用项目可见性，写入要求项目成员且未归档。继承原系统管理员真实权限，不提升 Coo 身份。
- 业务事件自动调查，任务创建/分析写入默认确认；自动留言仅限员工本轮明确授权。不是无限制自治。
