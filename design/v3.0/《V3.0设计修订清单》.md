# V3.0 设计修订清单

> 对应需求基线：V3.0-R3
> 当前状态：Figma V3.0-R3 候选稿已修订，待产品确认
> 更新日期：2026-08-24

## 1. 设计基线原则

- 优先修改可编辑设计源文件，再导出新的最终 PNG；
- 旧 PNG 保留为历史参考，但不作为 V3.0-R3 开发依据；
- 新导出文件必须使用高于旧稿的版本号，避免覆盖后无法追溯；
- 项目知识库不属于 V3.0，导航和页面中不得增加该入口；
- 本期只设计桌面 Web，最小内容宽度 1280px，宽内容允许横向滚动。

## 2. 全局修订

- 任务状态统一为待开始、进行中、已完成、已取消；
- “未完成”只作为筛选项，包含待开始和进行中；
- 优先级补齐 P0 重要紧急、P1 重要不紧急、P2 紧急不重要、P3 不紧急不重要；
- 所有甘特任务条统一蓝色，不再使用绿色等状态色；
- 甘特图任务行删除非功能性拖拽图标；
- 归档项目需要只读状态，写操作和拖拽禁用；
- 单个负责人达到 200 条任务时不增加专门面板状态，也不预先禁用入口；只在创建或转交提交失败时提示任务上限；
- 搜索或筛选无结果时保留成员或参与人员分组，数量显示 0。

## 5. 可由交互说明覆盖的状态

以下状态不要求分别制作完整页面，但设计系统或组件标注中必须能找到对应样式：

- 表单必填错误；
- 日期倒置；
- 描述达到 500 字；
- 页面加载和重新加载；
- 接口失败提示；
- 请求中的按钮禁用；
- 参与人员不可移除；
- 搜索或筛选无结果；
- 归档项目只读。
- 创建或转交任务时的成员任务上限错误提示。

## 7. 第三轮 QA 补充设计范围

以下页面和状态尚未包含在原 9 张团队任务与版本排期设计中，必须在对应前端功能开发前补齐：

- 登录/首次注册双模式：登录使用部门、姓名、公司统一密码；注册使用部门、姓名、邀请码；
- 项目成员管理弹窗或页面：从已注册用户中添加和移除成员；
- 部门删除确认及“仍被用户、项目或邀请码引用”的失败提示；
- 邀请码管理列表持续显示完整邀请码，并提供复制操作；
- 项目归档和重新打开入口：所有项目成员均可操作；
- 会话过期后返回登录页，并保留原目标地址。

数据库、后端、路由和测试基础可以先开发；团队任务、版本排期及上述新增页面的最终 UI 必须在设计冻结后再作为正式开发依据。
