## 2. 固定回归命令

```bash
cd backend
./.venv/bin/pytest -q

cd frontend
pnpm test
pnpm run build
pnpm run test:e2e
```

OpenAPI 和前端类型一致性由 `.github/workflows/quality.yml` 重新生成后执行 `git diff --exit-code` 检查。Playwright 用例必须使用一次性 SQLite 测试库。
